# Changelog

## [Unreleased]

### Added

- Deploy gate base rules (fix forward from the assurance re-check of #23). The base is the newest successful deployment whose commit is an ancestor of, or equal to, the commit being deployed, so a rollback to a commit that was never deployed is checked. `base_sha` is used only when no such deployment exists, must be a strict ancestor, and is otherwise ignored with a warning. The summary and log show the range and the number of deployments skipped. README limits gain the `deployments: write` residual, the `if: always()` warning and the `.jury-tools` path.
- Reusable `deploy-gate.yml` (CER-4034): the claims check, enforce only, on the range from the newest successful deployment of the caller's environment to the commit being deployed; outputs `sha` and `base`. The approval is the environment on the caller's deploy job. The claims step now lives in `scripts/claims_job.sh`, which `agent-jury.yml` and `deploy-gate.yml` both run.
- Agent Jury `claims check` job and `scripts/claims_check.py`: flags uncited guarantees, certifications, absolute claims, metrics and legal liabilities in added public text. The model classifies uncited hits. New input `claims_mode` (`enforce` default, or `report`). The script is checked out at `job.workflow_sha`. A `claims: proven <evidence>` marker cites one claim, and its evidence must resolve: a repo path at the PR head, a commit SHA in the repo, or an https URL on an allowlisted host. New input `claims_url_hosts` (default `github.com`). The job never fetches a URL. Added lines are normalised (HTML entities, NFKC, zero-width and soft-hyphen characters, look-alike letters) before matching. New categories `unreadable` and `obfuscation`. Scope is case-insensitive and adds `.htm`, `.markdown`, `.rst`, `README*`, `pricing/` and `landing/`. The job fails closed with exit code 2 on a malformed model answer, under `bash -e` as on the runner.

- Agent Jury `claims check` hardening (round 3). Evidence must be a regular, non-empty blob at the base branch tip that the PR does not change, and a cited SHA must be reachable from base; new input `claims_evidence_paths`, default `evidence/**,docs/evidence/**`, so an ordinary file such as README.md does not count as evidence. Markup that splits a word (HTML comments and tags, emphasis, escapes, link syntax) is removed before matching. Combining marks and blank-rendering characters are dropped (NFKD). Look-alike letters fold to Latin in every word. New input `claims_paths` replaces the default scope; the default adds `locales/`, `i18n/`, `*.njk` and `*.liquid` and leaves out licence files. The job diff uses `--no-renames`. Two consecutive added lines are matched as one phrase. A marker cites the next line only when it holds the whole line. The lexicon gains 11 terms. A repeated index in the model answer fails closed with exit code 2.

- Agent Jury workflow starts again when called: the `verdict_runner` description held a literal `${{ inputs.runner }}`, which GitHub rejects at startup (no context is available in an input description), so every caller run failed with zero jobs. It reached `main` on 2026-10-27 with #5 (commit aee22ac). No release tag contains it: callers pinned to v1 through v1.1.2 were not affected.
- Agent Jury `claims check` hardening (round 4). Attribute values inside tags are scanned, and a quoted `>` no longer ends a tag. A marker hides its text only when its evidence resolves. A cited SHA must change an evidence path; the root commit never cites. Breaking: input `claims_url_hosts` is now `claims_url_prefixes` (default empty, no URL cites; prefixes end with `/`). Reference links and code spans no longer split a word. One marker cites the longest hit and its direct overlaps. A zero-width joiner counts only between Latin letters. Accented words still fold onto English terms (fail closed); the model judge classifies French copy such as `assur\u00e9`. The lexicon gains ten phrases. README residual risks gain N-E (a PR can loosen its own caller workflow).

- Kubernetes architecture documentation and generator tooling covering estate system boundaries, Rust type systems, and custom resource catalogs.

### Fixed

- Agent Jury request-build and response-parsing failures now emit explicit error-tier outputs and retain jq diagnostics; file-backed prompt and request data avoid command argument size limits.
